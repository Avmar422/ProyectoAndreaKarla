<h1>Proyecto Andrea y Karla</h1>
<h2>BookFlow</h2>

<p>Se trata de una página web, que tiene el propósito de gestionar libros, utilizando todo lo aprendido en el curso.</p>

<h2>Parte 1 (Karla): Git, GitHub y manipulación del DOM</h2>

<p>En esta actividad se trabajó con:</p>
<ul>
  <li><b>HTML:</b> Estructura de la página sobre Genshin Impact.</li>
  <li><b>CSS:</b> Diseño y estilos visuales.</li>
  <li><b>JavaScript:</b> Manipulación del DOM para agregar interactividad.</li>
  <li><b>Git y GitHub:</b> Control de versiones y subida del proyecto.</li>
</ul>

<h2>Parte 2 (Andrea): CRUD y HTTP</h2>

<p>En esta sección se trabajó con la comunicación entre el cliente y el servidor:</p>

<ul>
  <li><b>CRUD:</b> Implementación de las operaciones básicas:
    <ul>
      <li><b>C (Create):</b> Crear datos en el servidor.</li>
      <li><b>R (Read):</b> Leer y mostrar los datos.</li>
      <li><b>U (Update):</b> Actualizar información existente.</li>
      <li><b>D (Delete):</b> Eliminar registros.</li>
    </ul>
  </li>
  <li><b>Servidor y HTTP:</b> Envío de peticiones al servidor para guardar y gestionar los datos.</li>
</ul>
